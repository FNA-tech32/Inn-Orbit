## 📖 About the Project

**Inn Orbit** is a modern, responsive, and interactive website designed for a luxury multi-cuisine restaurant and hotel. Built with clean semantic HTML5, modern CSS3 styling, and smooth JavaScript interactions, it delivers an immersive experience for diners exploring fine dining menus, membership subscriptions, customer feedback, and reservation bookings.

Whether visitors are searching for authentic Italian pasta, rich North Indian curries, savory Chinese dumplings, or comforting Asian ramen, **Inn Orbit** presents every dish with mouthwatering imagery, detailed descriptions, and transparent pricing.

---

## ✨ Key Features

- **Dynamic Animated Branding**: Powered by [Typed.js](https://github.com/mattboldt/typed.js/), dynamically showcasing brand identity (`Inn Orbit.`, `Taste Unique.`, `Finest Flavors.`) right in the navigation bar.
- **Responsive Mobile Navigation**: Clean hamburger drawer menu for mobile and tablet screens alongside smooth anchor scrolling.
- **Hero Showcase**: High-impact banner with appetizing visuals and immediate call-to-actions linking directly to the menu.
- **Heritage & Story (About Us)**: Highlights the restaurant's legacy since 1992, showcasing culinary philosophy and luxurious ambience.
- **Cuisine Categories**: Dedicated highlight cards for Indian, Chinese, and Italian cuisines with quick learn-more links.
- **Interactive Food Menu**: Responsive grid featuring signature dishes with appetizing images, rich descriptions, and prices in Indian Rupees (₹).
- **VIP Dining Subscriptions**: Tiered monthly membership packages (Basic, Premium, Elite) with complimentary meals, member discounts, and priority bookings.
- **Customer Testimonial Carousel**: Touch-friendly slider powered by [Swiper.js](https://swiperjs.com/) showcasing customer reviews, verified ratings, and photos.
- **Comprehensive Contact Section**: Integrated inquiry and reservation form featuring **both primary and alternative contact details** (phone, alt phone, email, alt email, and venue address).
- **Interactive Form Validation & Feedback**: Real-time client-side feedback upon inquiry submission and newsletter signup.
- **Floating Back-to-Top**: Custom animated SVG floating button that smoothly scrolls back to the top when page is scrolled down.

## 🚀 Getting Started

### Prerequisites

All you need is a modern web browser (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge). No server-side runtime (Node.js/PHP/Python) is strictly required to run the frontend.

### Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<your-username>/Inn-Orbit.git
   cd Inn-Orbit
   ```

2. **Open the project**:
   - Double click `index.html` at the root, or open `Project Food Menu/index.html` in your web browser.
   - Alternatively, with **VS Code**, right-click `index.html` and select **"Open with Live Server"**.
   - Or run a lightweight local HTTP server:
     ```bash
     # Using Python 3 (if installed)
     python -m http.server 8000
     ```
     Then navigate to `http://localhost:8000` in your browser.

## 🌐 Deployment

The project includes automated GitHub Pages deployment configured in `.github/workflows/static.yml`.

To deploy:
1. Push your changes to the `main` branch:
   ```bash
   git add .
   git commit -m "Update Inn Orbit branding, contact details, and documentation"
   git push origin main
   ```
2. In your GitHub repository settings, go to **Settings > Pages**.
3. Under **Build and deployment**, choose **GitHub Actions** as the source.
4. Your website will be automatically deployed and accessible worldwide!
